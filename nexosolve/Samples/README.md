# NexoSolve samples

Put reviewed, self-contained .gh or .ghx files directly in this folder. The initial library has no example files.

Publish embeds them in the GHA and includes them in the nexosolve/Samples distribution folder. Bump the coordinated app/plugin version when changing official samples.

Use NexoSolve > Help > NexoSolve Club > Browse samples. The list is refreshed each time. Official installed samples are always in %LOCALAPPDATA%/NexoSolve/App/Samples. Club > Open NexoSolve folder opens their parent folder, alongside the executable.

Opening creates a working copy under Documents/NexoSolve/Sample Projects. Save personal edits there. Updates may replace managed library files. A personal samples folder can be selected from Club's menu; it is never synchronized.

Review sample scripts before distribution and state required plugins inside the definition. Relative external assets are not copied by this implementation.
