# NexoSolve Downloads

Public binary downloads for NexoSolve on Windows x64, Rhino 8 and Grasshopper. Product source code is maintained separately. This repository contains release assets and installation instructions.

## Installation

1. Download NexoSolve.gha from Releases or food4Rhino. Put it in Grasshopper Libraries; remove older copies and restart Rhino.
2. Add NexoSolve > Help > NexoSolve Desktop to the Grasshopper canvas.
3. Click Download Desktop. Keep an internet connection while the verified package downloads.
4. On Nexo Connector, leave App Path blank and click Open NexoSolve.

Desktop installs in `%LOCALAPPDATA%\NexoSolve\App`. Study results are kept separately. Close NexoSolve Desktop before updating it.

## Manual installation

Download NexoSolve-Windows-x64.zip from the latest release, extract it to a permanent folder and set Connector App Path to Nexonest.NexoSolve.Desktop.exe. Verify the ZIP using the accompanying SHA-256 file when downloading manually.

NexoSolve Desktop checks and downloads Desktop updates. NexoSolve Club checks Grasshopper plugin updates and opens the release page; replacing the GHA requires restarting Rhino.
